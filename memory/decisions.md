## 2026-07-14 / reafirmado 2026-08-15 — Ubicación de la sección Transformaciones

**Decisión**: la sección de resultados/transformaciones (antes-después) va después del Hero,
o alternativamente después de la sección de tratamiento/proceso — ambas opciones válidas
según cómo quede el storytelling. También es una buena ubicación pegada a testimonios/
estrellitas. Se agrega un link en la navbar fija junto a inicios/tratamientos/primera consulta.

**Razón**: Lucas plantea la página como storytelling cohesivo (Hero → proceso/tratamiento →
resultados → sobre mí → diferenciación → testimonios → contacto). Raquel prioriza mostrar
resultados porque "cualquiera puede hacer todo lo demás, pero mostrar los resultados que uno
logra está bueno" — tiene casos lindos para exhibir.

**Alternativas descartadas**: ponerlo solo al final cerca del contacto (se descartó por
quedar "muy abajo", pierde visibilidad); esperar a definir el label exacto antes de avanzar
con el layout (se decidió avanzar con el layout y iterar el copy después — "mirar nuestros
resultados" / "mirar las transformaciones" son candidatos, no definitivo).

**Revisable**: sí, el label/copy exacto queda abierto (ver `open-questions.md`).
